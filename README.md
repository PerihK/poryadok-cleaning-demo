# Порядок · сайт клининга + CRM

Самостоятельный портфолио-проект с вымышленным брендом в Санкт-Петербурге. React 19 + Vite. Демо без реальных заказов, платежей и контактов компании.

[Открыть сайт](https://poryadok-cleaning-demo.vercel.app/) · [Форма заказа](https://poryadok-cleaning-demo.vercel.app/order) · [CRM](https://poryadok-cleaning-demo.vercel.app/admin)

## Запуск

    npm ci
    npm run dev
    npm test
    npm run build

Локальный адрес: http://127.0.0.1:5187. Маршруты: / — сайт, /order — форма, /admin — CRM. Демо-доступ открыт без регистрации.

## Возможности

Три шага заказа: уборка и площадь → дата, адрес и фото → контакты и подтверждение. Предварительная стоимость = площадь × тариф, но не меньше минимума по виду уборки, затем дополнения. Створки окон, площадь балкона, секции шкафов и кухонные приборы считаются отдельно. Тип помещения и периодичность не добавляют скрытых коэффициентов. Все суммы в рублях за одну уборку.

В CRM → «Тарифы» можно менять ставки и минимумы, сохранять их или возвращать исходные значения. Заявка сохраняет снимок расчёта с версией тарифов: новые настройки не меняют старые суммы.

CRM: список/карточки, поиск, фильтры, календарь, статусы, заметки, фото, история, CSV с предварительной суммой. Удаление в корзину с восстановлением.

Маска российского телефона поддерживает редактирование в середине строки и мобильный beforeinput. Фото JPEG/PNG/WebP: до 5 файлов по 10 МБ, сжатие до 1200 пикселей перед сохранением. Время московское, UTC+3; свободные слоты не проверяются.

Адресные подсказки: реальные данные OpenStreetMap через публичный Photon. Поиск с 3 символов, пауза 600 мс, отмена устаревших запросов, кеш на 10 минут. Текст поиска передаётся внешнему сервису Photon. При ошибке можно ввести адрес вручную. Ключ API не требуется; для рабочего проекта нужен провайдер с подходящей доступностью и условиями.

## Демо-данные

Заявки, сжатые фото и тарифы хранятся в IndexedDB только в текущем браузере на текущем домене. Черновик — в sessionStorage. Изменения синхронизируются между вкладками одного браузера. Серверной базы, авторизации и отправки обращений нет. После очистки данных браузера демо начинается заново. Примеры клиентов и адресов вымышлены. Для проверки используйте кнопку заполнения примера и демонстрационные данные.

Все цены условные: это не публичная оферта и не окончательная стоимость. В реальном сервисе итог согласовывается после уточнения объёма и состояния помещения. Демка не принимает настоящие заказы.

Гостиная — сгенерированная иллюстрация, не фото объекта или выполненной работы. Иконки Lucide, шрифт Manrope размещается локально. Реальных отзывов, рейтингов и привязки к действующей компании нет.

## Проверки и публикация

npm test: расчёт четырёх видов уборки, минимумы, количества, валидация тарифов, сохранение настроек и старых расчётов, полный цикл заявки с фотографией/статусом/корзиной, телефонная маска и адресный поиск.

18 автоматических проверок проходят. В браузере проверены размеры 320, 390, 768 и 1280 px: календарь с семью колонками, форма и дополнения, создание заявки с фото, CRM, статус и заметка после перезагрузки, корзина и восстановление, настройка тарифов, поиск и CSV. На опубликованной версии пройден путь «65 м² + балкон 4 м² → 8 550 ₽ → фото → CRM → В обработке». Проверки размеров выполнены в Chromium; нативный Safari на iPhone отдельно не запускался.

Отдельный проект Vercel. vercel.json обеспечивает прямые ссылки /order и /admin. Индексация отключена. Секреты и переменные окружения для сборки не нужны.
